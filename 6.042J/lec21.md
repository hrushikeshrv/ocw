# Lecture 21 - Random Variables

## Definitions

1. A random variable is just a function that maps every event in the sample space to a real number. It is just a way to represent every event in the sample space with a number
2. A characteristic, or bernoulli, or indicator random variable is a random variable that takes only two values \- 0 or 1\.
3. The notion of conditional probability also carries over from the probability of events to the probability that the random variable takes a certain value.
4. The notion of independence also carries over from the independence of two events to the independence of two random variables.
5. The probability distribution function (p.d.f) is a function which gives you the probability that the random variable takes some value x.  
   $f(x) = Pr(r.v. = x)$
6. The cumulative distribution function (c.d.f) is a function which gives you the probability that the random variable takes some value \<= x.

   $F(x) = Pr(r.v. <= x)$
