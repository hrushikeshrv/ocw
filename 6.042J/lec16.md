# Lecture 16 - Counting Rules 1

## Definitions

1. A set is an unordered collection of distinct elements.
2. The cardinality of a set is the number of elements in the set.
3. A sequence is an ordered collection of elements that are not necessarily distinct.
4. A permutation of a set is a set of sequences of items in the set such that each item occurs exactly once in a sequence.
